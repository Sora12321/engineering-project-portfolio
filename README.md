## How I work

I generally start with a concrete problem, learn the unfamiliar technical pieces, isolate a working first version, and only then add reliability features and expansion. I use AI coding tools to speed investigation and implementation, but keep correctness checks and technical decisions tied to tests, source data, and physical or software behavior.
