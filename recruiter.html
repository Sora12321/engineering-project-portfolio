Engineering software work — recruiter snapshot

Andrew Shoemaker | UW–Madison Aerospace Engineering

I build software for hard-to-automate tasks and engineering problems where correctness matters. Representative projects:

Local nutrition-data integration (Python / Playwright / SQLite). Built a browser-based workflow to transfer dining-menu nutrition into custom food records, with explicit save boundaries, exact readback checks, and duplicate prevention. Internal project records document a successful controlled Windows end-to-end save and readback. Existing-food editing and scheduling remain disabled.

Preliminary supersonic RC aircraft sizing model (Python / OpenVSP). Developed low-order analysis connecting drag, propulsion, inlet, trajectory, area-rule and concept optimization. Added an OpenVSP bridge and unit-level model tests. The tool supports sensitivity and concept screening; it is not a validated supersonic flight-performance prediction.

Cross-platform short-form video pipeline (Python / FFmpeg / Edge TTS). Built a local processing chain for story intake, narration, word-timed captions, rendering, thumbnails, and upload-ready packages; public-platform posting remains manual. Repo includes cross-platform regression checks.

Multi-user browser-session isolation study. Forked the personal integration into a controlled synthetic-account prototype to evaluate per-user browser state and isolation. Not deployed or production-certified.

Private source code. I can explain architecture, testing and tradeoffs; these project summaries do not expose account state, code, or sensitive assets.
