macOS Game UI Automation — Early Prototype

Status: Early experimental prototype; historically earlier than the Windows rewrite
Code: Private
Focus: Python, screen capture, OCR, desktop interaction

The problem

Explore whether an iPhone-mirroring workflow could be automated from a Mac by using screen recognition and action scripts.

Work represented in the repository

  • Initial OCR helpers to detect journey information and select a matching branch.
  • Separate modules for screen/mirroring access, interaction actions, and small diagnostic scripts.
  • Calibration and exploratory testing utilities for screen regions.

What it proves

The default-branch source is an early prototype, not a completed autonomous system. It helps explain the iteration path from Mac screen automation to the later Windows emulator implementation. The more complete Windows project is featured separately.

No live reliability or performance claims are made for this prototype.
